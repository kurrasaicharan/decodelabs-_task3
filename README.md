## 📌 Project Overview

The **Random Password Generator** is a Python-based project that creates strong and secure random passwords based on the user's required length.

The program generates passwords using:
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

It also analyzes the generated password and displays the password strength level.

---

## ✨ Features

✅ Generate random secure passwords  
✅ User-defined password length  
✅ Ensures password contains:
- Capital letters
- Small letters
- Digits
- Special symbols

✅ Password strength checker:
- Weak
- Medium
- Strong

✅ Displays password analysis:
- Total length
- Uppercase count
- Lowercase count
- Number count
- Special character count

✅ Option to generate multiple passwords
